Справка

Быстрый старт

  1. Установите LM Studio, скачайте модель (например Qwen2.5-7B-Instruct) и включите Local Server (вкладка Developer → Start Server, порт 1234).
  2. Запустите сервер Minecraft (или откройте мир «для сети» — порт будет показан в чате) версии не выше 26.1.
  3. На вкладке Настройки укажите адрес сервера, нажмите «Проверить и загрузить модели», выберите модель и сохраните.
  4. Нажмите Запустить. Бот зайдёт на сервер под указанным ником.

Как общаться с ботом

В игровом чате обращайтесь по имени: Боб, иди сюда, Боб, наруби 10 брёвен, Боб, построй дом из досок. В окне программы имя не нужно.

Команды напрямую (без нейросети): !help, !get_status, !come_here, !collect_block block=iron_ore count=5, !stop.

Режимы

Одна модель — проще, меньше памяти. Две модели — чат на быстрой модели, а новые навыки пишет сильная coder-модель (Qwen2.5-Coder, Devstral). Для видеокарты на 8 ГБ: 7B Q4 для чата; coder-модель LM Studio подгрузит при необходимости.

Самообучение

Если подходящего умения нет, бот пишет JavaScript-навык сам, проверяет его в песочнице и сохраняет в папку данных. Выученные навыки: !list_learned_skills, удалить: !forget_skill name=….

Безопасность

Не давайте боту права оператора. Сгенерированный код выполняется в ограниченной песочнице, но это не полная защита — запускайте бота только на своих серверах.
